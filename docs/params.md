# SysBioOncology/SPoTLIghT pipeline Parameters

Computational framework (SPoTLIghT) to derive spatial graph-based interpretable features from H&E (fresh-frozen, FF) tissue slides.

## SPoTLIghT

Parameters that are used in multiple modules

| Parameter                | Description                                                                                                                                                                                            | Type      | Default                                       | Required | Hidden |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------- | --------------------------------------------- | -------- | ------ |
| `spotlight_modules`      | indicate the modules to run.                                                                                                                                                                           | `string`  | extracthistopatho,predicttiles,computespatial |          |        |
| `cancer_type`            | abbreviation of cancer type, using TCGA abbreviations                                                                                                                                                  | `string`  | SKCM                                          |          |        |
| `slide_type`             | Slide type, i.e. FFPE or FF                                                                                                                                                                            | `string`  | FFPE                                          |          |        |
| `is_tcga`                | Indicate whether the H&E images are from the TCGA                                                                                                                                                      | `boolean` |                                               |          |        |
| `path_tissue_classes`    | Path to [tissue_classes.csv](assets/tissue_classes.csv), which is provided.                                                                                                                            | `string`  | assets/tissue_classes.csv                     |          |        |
| `tumor_purity_threshold` | Minimum tumor purity for a slide to be kept (default=80)                                                                                                                                               | `integer` | 80                                            |          |        |
| `clinical_file_path`     | Path to clinical file (`.csv`), at least have the following columns: 'sample_submitter_id' and 'slide_submitter_id'. If **module `extracthistopatho`** is run, setting this parameter is **optional**. |
| `string`                 |                                                                                                                                                                                                        |           |                                               |
| `var_names_path`         |                                                                                                                                                                                                        | `string`  | assets/task_selection_names.pkl               |          |        |
| `out_prefix`             | Prefix to use for selection of outputs                                                                                                                                                                 | `string`  |                                               |          |        |
